# /conclave-spec — Obsoleto

import { Callout } from 'nextra/components'

<Callout type="warning">
**`/conclave-spec` está obsoleto.** El wizard de configuración único se fusionó en [`/conclave-init`](/es/commands/init). Correr `/conclave-spec` te pedirá que corras `/conclave-init` en su lugar.
</Callout>

## Qué cambió

Antes Conclave usaba un flujo de dos comandos en el Día 0:

```bash
/conclave-init   # inicializar el workspace
/conclave-spec   # generar historias y arquitectura a partir de una idea
```

Esto se simplificó. `/conclave-init` ahora hace todo: detecta el stack, reúne nombre del proyecto, prefijo de historia, fecha de lanzamiento, perfil de equipo, y ubica el documento de planificación del producto — y después crea el workspace.

La generación de historias y sprints se movió permanentemente a `/conclave-planning` (Fase A).

## Nuevo flujo

```bash
/conclave-init        # wizard único — crea conclave/ y config.md
/conclave-planning    # genera historias + arquitectura desde tu doc de producto, y planifica el Sprint 1
```

Ver [`/conclave-init`](/es/commands/init) y [`/conclave-planning`](/es/commands/planning) para la referencia completa.
