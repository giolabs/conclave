# /conclave-spec — Deprecated

import { Callout } from 'nextra/components'

<Callout type="warning">
**`/conclave-spec` is deprecated.** The one-time project setup wizard has been merged into [`/conclave-init`](/en/commands/init). Running `/conclave-spec` will tell you to run `/conclave-init` instead.
</Callout>

## What changed

Previously Conclave used a two-command Day 0 flow:

```bash
/conclave-init   # bootstrap the workspace
/conclave-spec   # generate stories and architecture from an idea
```

This has been simplified. `/conclave-init` now does everything: it detects the stack, collects project name, story prefix, launch date, team profile, and locates the product planning document — then creates the workspace.

Story and sprint generation moved permanently to `/conclave-planning` (Phase A).

## New flow

```bash
/conclave-init        # one-time wizard — creates conclave/ and config.md
/conclave-planning    # generate stories + architecture from your product doc, then plan Sprint 1
```

See [`/conclave-init`](/en/commands/init) and [`/conclave-planning`](/en/commands/planning) for the full reference.
